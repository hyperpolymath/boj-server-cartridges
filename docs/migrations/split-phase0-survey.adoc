= Split Phase 0 — survey (read-only)
:revdate: 2026-10-07

Phase 0 of the BoJ split: move every cartridge off its vendored copy of
the host glue and onto one shared adapter library. This document records
the starting state. It changes no code. Every count carries the command
that produced it, so any row can be re-checked or falsified in one step
(the `+DEBT.adoc+` convention).

The per-cartridge ledger is
`+.machine_readable/migrations/split.jsonl+`: JSON Lines, one record per
`+cartridge.json+` manifest, each line I-JSON (RFC 7493) in JCS
(RFC 8785) canonical form (estate ruling D306). The plan originally
named an A2ML file in boj-server; A2ML is retired (D308), and the ledger
lives here because this is the repository whose counts move.

== The ledger

One record per manifest, keyed by `+path+` (unique) and `+name+`
(unique across all 142; checked). No identifiers are minted.

[cols="1,3"]
|===
|Field |Meaning
|`+name+` |the manifest's `+name+`
|`+path+` |the cartridge directory
|`+kind+` |`+domains+`, `+cross-cutting+` or `+templates+` (ADR-001). The one `+templates+` row is the authoring template, not a shipped cartridge; it is kept so the count reconciles with the manifest count.
|`+tier+` |the manifest's declared trust tier, verbatim. This is the re-audit baseline for the trust-tier ADR; nothing here asserts it is correct.
|`+has_ffi+`, `+has_adapter_dir+`, `+has_adapter_build+`, `+has_shim+` |presence of those files under `+path+`
|`+ffi_stub+` |at least one `+*_ffi.zig+` under `+path+` returns `+"status":"stub"+` (DEBT T-1 pattern)
|`+state+` |`+in-tree+` for every row. Later phases move a row to `+de-vendored+`, `+moved+` or `+blocked+`.
|`+prs+` |empty for every row: no split PR exists yet, so none was queried.
|`+reason+` |`+null+` unless `+state+` is `+blocked+`
|===

How the ledger was produced: for each manifest path from the tree
listing, the record was assembled with `+jq -c+` and passed through
`+ijson-jcs canon+` (`+hyperpolymath/ijson-jcs+` `+main+`, which carries the
CLI). How it is checked: `+ijson-jcs check+` takes whole files, not JSON
Lines, so each line was written to its own file and checked; 142 of 142
returned `+OK+`. Controls planted first: a line with keys out of order
returned `+NOT CANONICAL+` (rc 1) and a line with a duplicate key returned
`+INVALID+` (rc 2).

To re-check, from the repository root:

[source,sh]
----
n=0; while IFS= read -r l; do n=$((n+1)); printf '%s\n' "$l" > "/tmp/l$n.json"
  ijson-jcs check "/tmp/l$n.json" >/dev/null || echo "line $n"; done \
  < .machine_readable/migrations/split.jsonl
----

== The V-lang original

`+developer-ecosystem:v-ecosystem/v_api_interfaces/+`. The last commit
touching it is `+c3210732+` (2026-09-21, the rename to
unified-api-adapter). The entry point `+v_api_interfaces.v+` defines
`+interface ProtocolAdapter { port; start() }+` and
`+struct UnifiedApiAdapter+`. It wires 16 adapters on `+base_port+1..16+`.

[cols="2,3"]
|===
|Surface |State in the V original
|REST, gRPC, GraphQL |Real HTTP servers: `+rest.v+` 278 lines, `+grpc.v+` 396, `+graphql.v+` 359
|FlatBuffers, Bebop, JSON-RPC, WebSocket, MQTT, tRPC, Cap'n Proto, SOAP, VeriSimDB |Stubs: 17 lines each, they print a start-up line
|BSP, SCIP, IPFS, Arrow |One-line `+println+` structs in the entry file
|===

The suite wires in no cross-cutting controls: the three real servers bind
`+:port+`, with no host, auth, rate limit or TLS. Auth, zero-trust, proxy
and metrics live in separate modules that the suite does not import:
`+v_auth+`, `+v_zerotrust+`, `+v_proxy+` and `+v_metrics+`. The REST server
builds a shell command from a request path without quoting it
(`+rest.v+` L156–161). That is inferred from reading the code, not tested.
The V version is retired (V-lang ban, 2026-04-10) and is a reference for
*what* surfaces exist, never code to port. The in-repo reference for the
Zig shape is `+cartridges/domains/config/k9iser-mcp/adapter/+`: one
loopback listener, protocol-classified, every request passing an
exposure gate before one `+boj_cartridge_invoke+` call
(`+.claude/CLAUDE.md+`).

*Missing from unified-api-adapter:* every surface and control above.
For each protocol name, and for HTTP-server and auth terms,
`+git grep -il+` finds 0 files in its `+src/+`.
