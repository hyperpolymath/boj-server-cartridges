= ssg-mcp / adapter — unavailable native protocol boundary

== Purpose

The loopback adapter recognises the five declared SSG tools and reports HTTP
503 because no native SSG backend is wired. Unknown REST and gRPC-compat tool
names return 404. It does not build, preview, deploy or clean a site.

== GraphQL classification

GraphQL requests may be raw documents or JSON envelopes with a string
`query` and an optional `operationName`. The selector accepts one query or
mutation with one root field. It distinguishes an alias from the field name
and skips comments and quoted strings inside balanced argument and result
groups. An explicit operation name must match the document's single named
operation.

Recognised fields return 503. Unknown fields, multiple operations or root
fields, fragments, directives, unbalanced groups, and unsupported envelopes
return 400. This is a bounded unavailable-service selector, not a GraphQL
executor or complete grammar/schema validator. Recognising a field provides
no evidence that its arguments were type checked or that an SSG operation ran.

== Files and tests

`build.zig` depends on the sibling FFI module; `ssg_adapter.zig` contains
the protocol dispatch and inline routing controls. Run `zig build test` in
this directory. Controls preserve 503 for each declared tool, distinguish
unknown operations, and reject names that appear only in a comment, a string,
an alias or another operation. These checks make no backend availability
claim.
